# Security Policy

## Supported versions

Security fixes are currently provided for the latest `0.1.x` release only.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting or Security Advisory feature for this repository. Do not post credentials, login cookies, personal data, or unpatched vulnerability details in a public issue.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Reports will be acknowledged as capacity allows; no response or remediation deadline is guaranteed.

If you believe a NetEase account or credential has been exposed, revoke the affected session through the service before reporting the software issue.
